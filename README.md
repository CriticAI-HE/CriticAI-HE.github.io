## CriticAI's website

This repo contains the public website for CriticAI, a community of practice to critically enquiry about AI’s adoption in HE and influence in the decision-making processes to ensure that AI usage is aligned with academia’s ethos.

From a technical standpoint, this is a quarto site that gets rendered using CI when commits are pushed to this repository.

This project is originated by the [Institute for Research Software's Fellowship Programme](https://www.software.ac.uk/fellowship-programme/) for [2026](https://www.software.ac.uk/news/introducing-2026-fellowship-cohort-insights-and-celebrations)
